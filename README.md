# Практична робота №4

## Тема
Розробка діалогових вікон. Системні діалоги.

## Опис роботи
У межах практичної роботи створено програму «Текстовий редактор» у середовищі Visual Studio 2022 з використанням Windows Forms.

У програмі реалізовано:
- відкриття текстових файлів через OpenFileDialog;
- збереження файлів через SaveFileDialog;
- налаштування шрифту через FontDialog;
- виклик вікна параметрів друку через PrintDialog;
- команди «Копіювати», «Вирізати» та «Вставити»;
- контекстне меню для RichTextBox;
- пункт «Про програму» з інформацією про розробника.
